## 200 多毫秒的延迟，实际是什么体验

法兰克福本地 ping 大约 190ms，全国三网平均在 259ms 上下。分运营商看差别很大：联通约 197ms，电信约 251ms，移动约 330ms。移动用户占多数的话，这台机器的手感会比数字显示的更钝。本地测速下载能到 5.5MB/s 左右，折合四十多兆，离 200Mbps 的峰值还有距离，共享带宽的高峰期波动是常态。

路由走 DE-CIX 互联再回国，和 CN2 的 59.43 节点不是一回事。SSH 敲命令、跑脚本、定时任务、API 中转、往对象存储同步文件，这些都能正常用。远程桌面点一下等半秒、实时看后台数据、开视频会议，就别指望了。

## 不限流量不等于可以随便跑满

JustHost 的不限流量带 fair-share 条款，长时间占满端口会被限速或提醒。200Mbps 是峰值而不是保底，同一台物理机上还有别人。这两点决定了它的适用边界：日常几百 G 的建站流量、备份同步、轻量代理，用着很舒服；真要跑视频中转或大文件分发，200Mbps 的共享峰值撑不住，得去看按带宽计费的机型。

带宽是可以往上选的，1Gbps 那档要多付钱。多数轻量用途选最低的 200Mbps 就够，把钱花在内存上更实在。
